Privacy Policy

Desktop Widgets · Last updated October 16, 2026

Desktop Widgets is a personal Windows desktop app that I built for my own use. It is not offered to the public.

What Google data it uses

  • Google Calendar: to show my upcoming events, and to create events and meetings (including Google Meet links and guest invitations) when I ask it to.
  • Google Tasks: to show my tasks, mark them complete, and create new tasks when I ask it to.

How the data is stored

  • All processing happens on my own computer.
  • The app keeps a sign-in token for each account in a file on that computer so I don't have to sign in every time. It does not store my password.
  • Calendar and task data is only held in memory while the widget is running.

Sharing

The app does not send Google user data to any server other than Google's own, and does not sell, share, or transfer it to anyone. It is not used for advertising or analytics.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from myaccount.google.com/permissions, and by deleting the app's token files from the computer.
