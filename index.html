Desktop Widgets

A small set of personal desktop widgets for Windows 11, made for my own use.

The Calendar widget shows today's events and Google Tasks from my Google accounts, and lets me add events, meetings and tasks from the desktop. It uses the Google Calendar API and the Google Tasks API.

  • Runs only on my own computer.
  • Not offered to the public, and not sold.
  • Google data is never sent to any server other than Google's own.
